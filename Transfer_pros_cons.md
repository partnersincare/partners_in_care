# Azure functions vs VM/local deployment

## Azure functions

Pros:

- Cheaper
- Cloud based (Scalable)

Cons:

- Less accessible source code
- More technical overhead and points of failure
- More investment to set up

## VM/Local

Pros:

- Source code is more easily accessible and modifiable
- Faster set up and deployment
- Development and troubleshooting are more straightforward with direct access to logs, files, and resources.
- Dedicated resources, avoiding potential performance fluctuations due to shared cloud infrastructure.
